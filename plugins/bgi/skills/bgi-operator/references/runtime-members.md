# 本体成员补足（非常规路径）

常规接口缺少反射登记时，宿主本体方法仍可能存在。先保留当前目录未命中或接口缺失的真实缺口凭据；不要把缺项当作权限关闭，也不把源码声明当成已执行。

通过离线源码定位业务类型和方法，再在当前接口目录查找运行时成员发现能力。核对已加载类型、公共方法、精确重载、输入契约、构造器和取消参数；有明确类型名时直接检查，不反复猜中英文关键词。不因为已有 UI 反射就绕行输入框和按钮。

选择当前可准备的简单参数重载，按真实参数名填入本次数据。准备只产生预览，不构造业务对象；核对语义、原方法、构造器和参数符合本次用户目标后，提交一次性计划执行。由宿主原生任务执行器负责锁、初始化与取消，不重写业务流程，不手动拼接键鼠动作。

成员、计划和构造器引用都只属于本次桥会话，不保存进快捷或定时任务。过期、签名变化和结果未知分别处理；不得自动重试可能已产生副作用的执行。方法返回不代表游戏业务成功，继续使用本次日志或结果核验。

复杂对象没有受支持的构造契约时明确报告适配缺口，不伪造对象字段。只有常规接口和本体成员两条非 UI 路径均有不可用证据、确实迫不得已，且用户没有禁止时，才考虑最低优先级的界面操作。
